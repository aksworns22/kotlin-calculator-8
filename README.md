# kotlin-calculator-precourse

## 구현할 기능 목록

- [x] 빈 문자열이 들어오는 경우
- [x] 커스텀 구분자만 정의하는 경우
- [x] 단일 숫자가 입력으로 들어오는 경우
- [x] 구분자만 입력으로 들어오는 경우
- [x] 두 숫자가 쉼표를 구분자로 입력되는 경우
- [x] 여러 숫자가 콜론을 구분자로 입력되는 경우
- [x] 여러 숫자에 대한 합을 구하는 기능
- [x] 커스텀 구분자를 사용하는 경우
- [x] 커스텀 구분자와 기본 구분자를 사용하는 경우
- [x] 2글자 이상의 문자열을 커스텀 구분자로 사용하는 경우
- [x] 음수를 입력받는 경우
- [x] `-`를 구분자로 사용하는 경우
- [x] 정의되지 않은 문자를 사용하는 경우
- [x] 결과가 최대 데이터 범위를 넘어가는 경우
- [x] 구분자를 연속해서 사용하는 경우
- [x] 구분자로 입력을 시작하는 경우
- [x] 구분자로 입력이 끝나는 경우
- [x] 숫자를 커스텀 구분자로 사용하는 경우
- [x] 연속된 숫자를 입력받는 경우

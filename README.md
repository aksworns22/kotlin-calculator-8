# kotlin-calculator-precourse

## 구현할 기능 목록

- [x] 빈 문자열이 들어오는 경우
- [x] 커스텀 구분자만 정의하는 경우
- [x] 단일 숫자가 입력으로 들어오는 경우
- [x] 구분자만 입력으로 들어오는 경우
- [x] 두 숫자가 쉼표를 구분자로 입력되는 경우
- [x] 여러 숫자가 콜론을 구분자로 입력되는 경우
- [x] 여러 숫자에 대한 합을 구하는 기능
- [x] 커스텀 구분자를 사용하는 경우
- [x] 커스텀 구분자와 기본 구분자를 사용하는 경우
- [x] 2글자 이상의 문자열을 커스텀 구분자로 사용하는 경우
- [x] 음수를 입력받는 경우
- [ ] `-`를 구분자로 사용하는 경우
- [ ] 커스텀 구분자로 빈 문자열이 들어오는 경우
- [ ] 정의되지 않은 문자를 사용하는 경우
- [ ] 결과가 최대 데이터 범위를 넘어가는 경우
- [ ] 구분자를 연속해서 사용하는 경우
- [ ] 구분자로 입력을 시작하는 경우
- [ ] 구분자로 입력이 끝나는 경우
- [ ] 숫자를 커스텀 구분자로 사용하는 경우

## 기본 제공 테스트

| 테스트 케이스    | 입력       | 출력                         | 통과 여부 |
|------------|----------|----------------------------|-------|
| 커스텀 구분자 사용 | `//;\n1` | `결과 : 1`                   |       |
| 예외 테스트     | `-1,2,3` | `IllegalArgumentException` |       |
